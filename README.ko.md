### 장기 로드맵: 전 스타일 스틱맨 디렉터 라이브러리 구축

이 프로젝트는 인터넷에서 주목받는 인기 스틱맨 비주얼 스타일을 모두 집대성하기 위해 제가 진행하는 장기 오픈소스 프로젝트입니다.

스틱맨을 아우르는 약 10가지 특색 있는 스타일을 체계적으로 정리했습니다. 앞으로도 새로운 스타일을 지속적으로 업데이트할 예정이니, 놓치지 않으시려면 Star를 눌러 주세요:

- **스타일 3: 시트콤 / 2인 대화 스타일** —— 두 캐릭터 간의 티키타카, 감정 대립, 직장인 속마음 대변 및 일상 풍자
- **스타일 4: 2D 스틱맨 × 사실적 3D 배경** —— 차원 충돌의 시각적 재미, RPG 초보자 마을 모험, 판타지 이세계 여정
- **스타일 5: 일타강사 / 과학 토크쇼 스타일** —— 칠판 교구 상호작용, 명쾌한 해설, 어려운 지식의 쉬운 전달
- **스타일 6: 손그림 동화책 / 기사 모험 스타일** —— 포근한 힐링 동화, 고전 우화, 따뜻한 어린이 스토리
- **스타일 7: 열혈 그래피티 / 액션 격투 스타일** —— 미니멀하고 박진감 넘치는 액션 콘티, 연속 콤보 대결, 묵직한 타격감
- **스타일 8: 선사 동굴 / 블랙 코미디 스타일** —— 시대적 반전 매력, 원시인의 엉뚱한 발상, 유쾌한 반전 드라마
- **스타일 9: 인기 로그라이크 카드 / 보스전 스타일** —— 스탯 폭발의 쾌감, 몬스터 사냥 및 레벨업, 게임 영상 해설

#### 앞으로 집중할 3대 개발 방향:
1. **전 스타일 커버리지**: 스틱맨의 다양한 매력적인 스타일을 모두 포괄하여, 모든 분야의 크리에이터가 즉시 활용할 수 있도록 지원합니다;
2. **고품질 콘텐츠 원천 해결**: AI에 단순 프롬프트를 맡겨 무작위로 생성하는 것이 아니라, 검증된 바이럴 콘텐츠를 분석·요약·추출하여 맞춤형 각색 스크립트를 제공합니다;
3. **스틱맨 전용 웹 스튜디오**: 스타일이 많아짐에 따라 Skill 인터페이스를 넘어 온라인에서 직접 효과를 미리 보고, 바이럴 대본을 고르고, 원클릭으로 프롬프트를 복사할 수 있는 전용 웹사이트를 준비하고 있습니다.

## 대본이 있다고 해서 영상이 완성된 것은 아닙니다

좋은 아이디어도 인물 한 명, 배경 하나에 머물러 10초 동안 시각적 변화가 거의 없는 단조로운 애니메이션으로 끝날 수 있습니다. 영상을 제대로 연출하려면 강렬한 오프닝 훅, 설명 템포 조절, 내용에 맞는 시각적 은유, 카메라 무빙, 장면 전환, 그리고 여러 번의 생성 간 일관성 유지까지 모두 설계해야 합니다.

**Flash Video Director는 생성 크레딧을 소비하기 전에 이러한 제작 단계의 고민을 먼저 해결합니다.**

## 숏폼 크리에이터에게 필요한 이유

| 강점 | 얻을 수 있는 결과 |
|---|---|
| **더 강력한 스토리 구조** | **완주시청률 60% 돌파를 위한 5단계 심류 모델**(골든 훅 → 상식 파괴 → 비밀 공개 → 진실 규명 → 여운과 인터랙션)을 적용하여 감정 리듬과 몰입도를 극대화합니다. |
| **자유로운 영상 길이 설정** | 30초, 60초, 90초, 3분, 5분 등 10초 단위의 원하는 길이로 제작 가능 (기본 60초). |
| **확실한 승인 체크포인트** | 최종 프롬프트를 만들기 전에 읽기 쉬운 디렉터 기획안을 먼저 확인. 수정 비용이 낮을 때 이야기를 다듬을 수 있습니다. |
| **풍부하고 관련성 높은 모션** | 각 클립마다 3개의 타이밍 비트를 설계하고 시각적 은유, 배경 변화, 카메라 이동, 텍스트 포인트, 반응, 전환, BGM, SFX를 배치합니다. |
| **완벽한 제작 조건 고정** | 캐릭터, 선 굵기, 팔레트, 목소리, 대사, 오디오, 전환 및 네거티브 프롬프트를 매 프롬프트에 반복 명시합니다. |
| **화면비에 맞춘 연출** | `9:16`, `16:9`에 맞춰 구도, 카메라 경로, 자막 배치를 재설계하며, 비율 태그만 단순 교체하지 않습니다. |
| **통제된 고대비 비주얼** | 흰 배경·검은 인물, 검은 배경·흰 인물과 최대 3개의 고채도 포인트 컬러를 지원합니다. |
| **원문에 대한 충실성** | 근거 없는 통계, 조작된 인용문, 과장된 제품 주장을 임의로 덧붙이지 않습니다. |

### 핵심 서사 엔진: 완주시청률 60%를 돌파하는 5단계 감정 흐름

완주시청률이 60%를 넘는 떡상 영상들은 감정의 긴장과 리듬이 매우 정교합니다. 간단한 키워드든 장문의 원문이든, Skill이 자동으로 5단계 감정 고조 모델로 재구성합니다(영상 총 길이에 맞추어 유동적 배분):

1. **골든 훅 (Golden Hook)**: 시작과 동시에 상식을 깨는 결정적 질문이나 시각적 대비를 전격 제시(숏폼은 보통 2~5초 이내 등장), 호기심을 완벽 장악;
2. **상식 파괴 (Disrupt Assumptions)**: 누구나 당연하게 믿던 통념을 먼저 짚은 뒤, 단 한 문장으로 산산조각 내어 인지적 충격을 형성;
3. **비밀 공개 (Unveil Secrets)**: 대중에게 잘 알려지지 않은 이면의 디테일이나 핵심 메커니즘을 밝혀 호기심을 극대화;
4. **진실 규명 (Ultimate Truth)**: 비즈니스 본질이나 인간 심리에 입각한 명쾌한 해답을 제시하여 지적 쾌감과 카타르시스를 제공;
5. **여운과 인터랙션 (Elevation & Discussion)**: 핵심 교훈을 명언으로 승화하고, 댓글 창에서 토론과 의견 표출을 유도하는 질문 제시.

별도의 API나 MCP 설정이 필요 없습니다. Skill을 설치하고 호출한 뒤, 대화형 안내에 따라 제작을 완료하세요.

## 붙여넣기 → 선택 → 승인 → 생성 → 편집

1. **붙여넣기:** 원고, 메모, 기사 또는 주제어만 입력합니다.
2. **선택:** 화면비(`16:9` 또는 `9:16`), **영상 길이**(10초 단위: 30초, 60초, 3분, 5분, 기본 60초), 비주얼 스타일(스타일 1 미니멀, 스타일 2A 스튜디오 테크, 스타일 2B 시네마틱 스토리 등)을 지정합니다.
3. **승인:** 영어 VO, 참고 번역, 비주얼 구성, 카메라 무빙, 전환, BGM, SFX가 포함된 디렉터 기획안을 확인합니다.
4. **생성:** 기획안 승인 후, 씬 수에 맞춘 독립형 Gemini Omni Flash 프롬프트(기본 6개)를 생성합니다.
5. **편집:** 약 10초 분량의 클립들을 이어 붙여 완성도 높은 고품질 최종 영상을 완성합니다.

화면비, 영상 길이, 스타일, 테마, 내레이션, 장면 구성, 색상, 목소리, 톤은 언제든 수정 가능합니다. 전체적인 변경 사항이 발생하면 Skill은 제안 단계로 돌아가 재승인을 요청합니다.

## 최종 전달 결과물

- 크리에이터를 위한 영어 제목, 핵심 메시지, 오프닝 훅, 톤앤매너, 컬러 팔레트, 음성 및 배경음악 방향
- 영상 길이에 맞추어 유연하게 조율된 영어 내레이션(10초당 약 20~25단어, 60초 기준 약 120~150단어)
- 2~3초마다 뚜렷한 시각적 변화를 주는 유기적인 스토리보드 씬
- 정확한 영어 대사 및 참고용 번역
- 씬 수에 맞추어 생성되는 독립형 Gemini Omni Flash 프롬프트(기본 6개, 타이밍 비트 및 네거티브 제약 포함)
- 클립 간 매끄러운 연결을 위한 시작과 끝 장면의 맞춤 설계
- BGM, 효과음(SFX), 연속성 유지 및 최종 편집 가이드

## 💡 초저비용으로 영상 제작하기: Gemini Omni Flash 빠른 시작 가이드

AI 영상 생성을 처음 접하시는 분들이 자주 묻습니다: “프롬프트는 어떻게 쓰나요? 비용이 비싸지 않나요?”

**결론부터 말씀드리면: 비용은 거의 들지 않으며, 누구나 손쉽게 1일 1영상 업로드가 가능합니다!**

Gemini Omni Flash는 뛰어난 동작 연속성과 일관된 캐릭터 유지 능력으로 현존 최고의 AI 비디오 모델 중 하나로 손꼽힙니다. 구글 공식 영상 제작 플랫폼인 **Google Flow** (`https://labs.google/fx/tools/flow`) 에서는:
- **클립당 단가가 매우 저렴**: Google Flow에서 10초 분량의 720P 영상 하나를 생성하는 데 약 15포인트만 소모됩니다;
- **매월 1,000포인트 무료 제공**: Google AI Pro 구독 시 매달 1,000 비디오 포인트가 지급되어 10초 클립 60편 이상 제작 가능, 일상적인 쇼츠 운영에 충분합니다;
- **극가성비 계정 활용**: 정가는 월 $19.99이지만, 글로벌 프로모션 계정 등을 활용하면 몇천 원대로 최상위 비디오 생성을 자유롭게 이용할 수 있습니다(이미지 생성은 포인트 차감 없이 완전 무료);
- **상세 실전 가이드**: 더 자세한 비용 절약 노하우와 Flow 세팅 방법은 제가 작성한 상세 튜토리얼을 참고하세요: [《Google Flow 쾌속 실전 가이드: Gemini Pro로 무제한 이미지 생성 및 1위 영상 모델 활용법》](https://x.com/CrazyKaomei/status/2093893997223923822?s=20).

## 설치 방법

저장소를 클론합니다:

```bash
git clone https://github.com/kaomei/stickman-video-director.git
cd stickman-video-director
```

설치 가능한 Skill 폴더를 Codex skills 디렉터리에 복사합니다:

```bash
cp -R skills/directing-flash-videos "${CODEX_HOME:-$HOME/.codex}/skills/"
```

Codex를 재시작하여 사용 가능한 스킬 목록에 나타나게 한 뒤, 스킬을 호출하고 소재를 입력합니다:

```text
$directing-flash-videos
```

## 반복 수정에 최적화, 생성 편차에 솔직하게

- **승인은 명시적이어야 합니다.** 현재 기획안이 승인되기 전까지는 Phase B로 진행하지 않습니다.
- **전체 변경 시 재연출을 진행합니다.** 새로운 화면비, 영상 길이, 스타일은 단순 텍스트 치환이 아닌 연출 전체를 다시 설계합니다.
- **프롬프트는 독립적으로 작동합니다.** 단일 클립을 생성하는 데 필요한 필수 고정 조건을 매 프롬프트마다 명시합니다.
- **철저히 원문에 근거합니다.** 구조와 표현은 극대화하되, 출처 없는 허위 주장을 임의로 덧붙이지 않습니다.
- **오디오에는 미세한 편차가 있을 수 있습니다.** 독립된 비디오 생성 특성상 음성이나 음악에 미세한 차이가 발생할 수 있습니다. 완벽한 일관성을 원하신다면 각 클립의 동기화된 SFX를 살리고, 최종 편집 시 연속된 외부 나레이션과 BGM 트랙을 추가하는 것을 권장합니다.
