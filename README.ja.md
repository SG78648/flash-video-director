#### 今後注力する3大方針：
1. **全画風の網羅**：棒人間にはまだまだ魅力的なスタイルが存在します。あらゆるヒット画風を網羅し、各ジャンルのクリエイターがすぐ使えるようにします。
2. **優良コンテンツ発信の仕組み化**：AIに単にプロンプトを投げて適当に作らせるのではなく、バズったコンテンツの構成を分析・抽出し、即戦力となるリライト台本を提供します。
3. **棒人間専用Webスタジオ**：スタイルが増えていく中で、Skillだけでは一覧性が足りなくなるため、オンラインで効果を確認し、台本を選んでワンクリックでプロンプトをコピーできる専用サイトを計画しています。

## 台本があるだけでは、まだ動画ではありません

良いアイデアでも、ひとりの人物、ひとつの背景、そして10秒間ほとんど変化しない平坦なアニメーションになってしまうことがあります。1本の動画を演出するには、冒頭のフック、説明のテンポ、内容に合う視覚的メタファー、カメラワーク、シーン接続、さらに別々の生成をまたぐ一貫性まで設計する必要があります。

**Flash Video Director は、生成クレジットを消費する前に、そうした制作判断をすべて整理します。**

|---|---|
| **強いストーリー構成** | **完走率60%超の5段階エモーショナル心流モデル**（黄金フック → 常識の打破 → 内幕の開示 → 真相の解明 → 昇華とディスカッション）を採用し、緩急を極限までコントロール。 |
| **自由な動画時間の指定** | 30秒、60秒、90秒、3分、5分など、10秒の倍数なら自由な長さで制作可能（デフォルト60秒）。 |
| **明確な承認ポイント** | 最終プロンプトを生成する前に、読みやすいディレクタープランを提示。手戻りのコストが低い段階でストーリーを調整できます。 |
| **密度が高く、意味のある動き** | 各クリップに3つの時間ビートを設計し、視覚的メタファー、環境変化、カメラ移動、テキスト演出、反応、トランジション、BGM、効果音を網羅。 |
| **確実な制作ロック** | キャラクター、線幅、パレット、声、台詞、オーディオ、トランジション、ネガティブプロンプトを各プロンプト内で徹底保持。 |
| **画面比率に合わせた演出** | `9:16`、`16:9` に合わせて構図、カメラワーク、テキスト位置を再設計（比率タグの機械的置換ではありません）。 |
| **制御された高コントラスト** | 白背景・黒人物、黒背景・白人物に加え、最大3色の高彩度アクセントを活用。 |
| **素材への忠実性** | 根拠のない事実、統計、引用、誇大広告を勝手に追加しません。 |

### コアストーリーエンジン：完走率60%を突破する5段階エモーショナル心流

完走率60%を超えるような人気ショート動画は、感情の起伏とリズムが極めて綿密に計算されています。シンプルなテーマでも生の原稿でも、Skill が自動的に5段階の感情エスカレーションモデルへと再構成します（動画の総秒数に合わせて柔軟に尺を配分）：

1. **黄金フック (Golden Hook)**：冒頭で反常識な問いかけや強烈な視覚的落差を一瞬で提示（ショート動画では通常2〜5秒以内に出現）、好奇心を一気にロック；
2. **常識の打破 (Disrupt Assumptions)**：誰もが信じている「当たり前」を提示した直後、一言でそれを覆して認知の摩擦を生み出す；
3. **内幕の開示 (Unveil Secrets)**：あまり知られていない裏側のディテールや仕組みを明かし、興味を最高潮まで引き上げる；
4. **真相の解明 (Ultimate Truth)**：ビジネスの本質や深層心理に基づいた決定的な答えを提示し、納得感と知的爽快感をもたらす；
5. **昇華とディスカッション (Elevation & Discussion)**：要点を金言としてまとめ上げ、コメント欄で議論したくなる問いを投げかける。

API や MCP への依存はありません。Skill をインストールして呼び出し、対話形式でそのまま制作を完了できます。

## 貼る → 選ぶ → 承認する → 生成する → つなぐ

1. **貼る：** 文章、メモ、記事、またはテーマだけでも入力できます。
2. **選ぶ：** 画面比率（`16:9` または `9:16`）、**動画の長さ**（10秒単位：30秒、60秒、3分、5分など、デフォルト60秒）、画風（スタイル1 白黒ミニマル、スタイル2A ミニマルテック、スタイル2B シネマティックストーリー、その他予定スタイル）を指定します。
3. **承認する：** 英語VO、参考訳、映像、カメラ、トランジション、BGM、効果音を含む詳細なディレクタープランを確認します。
4. **生成する：** 提案承認後、シーン数に応じた独立 Gemini Omni Flash プロンプト（60秒なら6本）を受け取ります。
5. **つなぐ：** 約10秒のクリップをつなぎ合わせ、一貫したハイクオリティ動画に仕上げます。

比率、長さ、スタイル、テーマ、ナレーション、シーン構成、配色、声、トーンはいつでも変更できます。全体設定を変えると提案段階に戻り、再承認を求めます。

## 受け取れるもの

- クリエイター向けの英語タイトル、中心メッセージ、フック、トーン、配色、声、音楽方針
- 動画の長さに応じた英語ナレーション（10秒あたり約20〜25語、60秒で約120〜150語）
- 2〜3秒ごとに変化がある、互いに連続性を持った絵コンテシーン
- 正確な英語台詞と参考翻訳
- 時間ビートとノイズ防止条件を含む、シーン数に応じた独立 Gemini Omni Flash プロンプト（デフォルト6本）
- クリップ間をつなぎやすくする、対応した終わり方と始まり方
- BGM、効果音、一貫性維持、最終編集のアドバイス

## 💡 低コストで動画を生成する方法：Gemini Omni Flash 速習ガイド

AI動画生成を始めたばかりの方から「プロンプトはどう使えばいい？コストが高そう」という声をよく聞きます。

**答えは：コストはほぼゼロに近く、個人でも毎日投稿が余裕で実現できます！**

Gemini Omni Flash は、アクションの連続性とキャラクターの一貫性が極めて高く、現行トップクラスのAI動画モデルとして広く評価されています。Google公式の映像制作プラットフォーム **Google Flow** (`https://labs.google/fx/tools/flow`) では：
- **1本あたりのコストが格安**：Google Flow では、10秒の 720P 動画1本の生成にかかるポイントはわずか約15pt；
- **毎月 1,000pt が付与**：Google AI Pro 会員なら毎月 1,000pt が付与され、10秒クリップを約60本以上生成可能。日常的な発信には十分すぎる量です；
- **驚くほど低価格で利用可能**：通常は月額 $19.99 ですが、海外キャンペーン経由などで手頃に入手でき、画像生成はポイント消費なしで完全無制限；
- **詳しい実践チュートリアル**：詳しい設定方法やお得な活用法は、私が執筆した解説記事をご覧ください：[《Google Flow 活用完全攻略：Gemini Pro で解放する無制限画像生成＋最高峰動画モデル》](https://x.com/CrazyKaomei/status/2093893997223923822?s=20)。

## インストール

リポジトリをクローンします：

```bash
git clone https://github.com/kaomei/stickman-video-director.git
cd stickman-video-director
```

インストール可能な Skill フォルダを Codex の skills ディレクトリへコピーします：

```bash
cp -R skills/directing-flash-videos "${CODEX_HOME:-$HOME/.codex}/skills/"
```

Codex を再起動し、Skill を利用可能にします。その後呼び出して素材を入力してください：

```text
$directing-flash-videos
```

## 修正しやすく、生成上の差異にも正直

- **承認は必ず明示的に行います。** 現在の提案を承認するまで Phase B へ進みません。
- **全体変更では再構成します。** 新しい比率や時間、スタイルは、機械的なテキスト置換ではなく演出から組み直します。
- **各プロンプトは独立しています。** 単独生成に必要な重要固定条件を毎回含めます。
- **意味の根拠を守ります。** 構成や表現は磨き上げても、根拠のない主張は追加しません。
- **音声には差が出る場合があります。** 個別生成では声や音楽が少し変わることがあります。最大限の一貫性を求める場合は、各クリップの同期効果音を残し、編集時にひとつの連続した外部ナレーションとBGMを重ねてください。
