# Improving Mechanism

This repo now has a self-improvement loop. Every iteration ends with (1) a quality
gate and (2) a retro note. Both exist so the next iteration starts smarter than the
previous one.

## The loop

1. **Edit** — change `generate_video.py`, `sfx_gen.py` or narration in CLIPS.
2. **Render** — `python generate_video.py` (or `python remix.py` when only audio/SFX changed).
3. **Gate** — `python qa_check.py --spot` prints a PASS/FAIL scorecard and writes `output/qa_report.json`.
   - Exit code `1` on any FAIL. An iteration is not done until it passes.
   - Cap: score 10/10 with no FAIL. Treat anything below as unfinished work.
4. **Retro** — append to this file (below) what changed, what the QA caught, and
   what the next iteration should do differently.

## Rules that are now enforced by the gate

- Final must be 1080x1920 @ 24fps, h264+aac, duration 35–75s.
- Every mixed audio track must be audible (mean >= -34 dB) without clipping
  (peak <= -0.3 dB) and not too quiet (peak >= -13 dB).
- Every clip must have exactly 3 valid, ascending, in-bounds beat ranges.
- Rendered frame count must match `int((mp3_dur + pad_before + pad_after) * FPS)`
  exactly — a mismatch means scene/animation timing will desync from narration.

## Tuning knobs and their side effects

| Knob | Location | Effect | Cache to invalidate |
|---|---|---|---|
| `RATE` (voice speed) | `generate_video.py` | shorter/tighter speech + regenerated word beats | `output/audio/clipN.mp3`, `output/timing/clipN.json` |
| `PAD_BEFORE` / `PAD_AFTER` | `generate_video.py` | post-beat silence after narration | frames |
| `sfx_gain` (+ per event gain) | `compile_video`/`sfx_events` | SFX loudness vs narration | remix only |
| `--spot` frames | `qa_check.py` | export per-clip stills for eyeballing | n/a |
| SS (supersample) | `generate_video.py` | 2x anti-alias fidelity vs render time | frames |

Remember: changing `RATE` or `VOICE` regenerates word timings, so beat-locked
animations stay in sync automatically — but old cached mp3/json are reused by
`gen_all_audio` if both exist, so delete them when you want a re-voice.

## Lessons learned (mistakes, causes, rules)

| # | Mistake | Cause | Rule |
|---|---|---|---|
| 1 | Word timing came back empty | edge-tts 7.2.8 defaults to `SentenceBoundary`; word events need `boundary="WordBoundary"` | Always pass `boundary="WordBoundary"` |
| 2 | Word offset crash | key was `offset`/`duration`, sometimes `Offset`/`Duration` | Use `chunk.get(x, chunk.get(x.capitalize()))` |
| 3 | `ImageDraw` object has no `.save()` | wrong API guess | Specialized object crashed at runtime, not import time — compile checks miss this |
| 4 | `ease()` renamed but 3 call sites missed | silent rename | Grep every symbol before/after rename (`python -c 'import ast...'`) |
| 5 | `Set-Content -Encoding UTF8` injects BOM | PowerShell default | `Write/` files or explicit no-BOM write |
| 6 | Random reversed bbox crashed clip4 | `randint` could yield y1>y2 on late beats | Clamp/order bbox before drawing; QA beat bounds catch drift |
| 7 | Cartoony synth SFX misjudged | guessed the vibe instead of asking | Download real CC0 SFX (`videoeditingsfx.com/sounds/<name>.mp3`, direct URL) |
| 8 | Dead `cubic()` + identical if/else branches | refactor residue | AST pass for unused defs; dedupe identical branches |
| 9 | QA tool itself buggy on first run | volumedetect log prefix + mp3 has trailing silence beyond last word | Mirror `render_clip`'s computation exactly; parse ffmpeg log tokens robustly |
| 10 | 8/10 result had no measurement | no objective gate | `qa_check.py` scorecard; iterate until 10/10 |

## Retro - iteration 5 (beat switches still too fast -> softened dissolves) - 2026-09-10

- **User feedback:** switches were still too fast; the fast crossfade double-exposed two mismatched compositions and read as animation glitches. Pace was fine; smoothness was not.
- **What changed (render_frame):**
  - Dissolve window CF 3 -> 6 frames (0.25s).
  - Replaced raw crossfade with `soft_blend`: smoothstep progress into a brightness dip (down to ~45% mid-transition) before blending. Composition changes now dissolve through dark instead of ghosting/overlapping mismatched elements -> no more double-image flicker.
  - Same soft_blend used for clip-open fade-in from black.
  - Fixed PIL `Image.point` LUT: RGB needs 768 entries (`range(256)*3`), not 256.
- **QA gate:** 35/35 PASS, score 10.0/10, 63.65s, 6.3MB -> `output/income_vs_wealth_2026-09-10_233930.mp4`.
- **Lesson:** fast crossfades between compositionally different scenes create visual noise; dissolve-through-dark (or dip-to-black) hides the mismatch and reads as smooth. Always pair LUT length with image mode.
- **Next ideas:** allow per-beat transition timing (some dissolves shorter/longer); check subjective feel of CF=6.

## Iteration 12 - cinematic upgrade pass + pop_text scale bug (*harder_to_ignore* story)
- **Goal:** user feedback on Iteration 11's output was "it's not at the level where a video editor will create something like this using after effects" — close that gap while staying inside the existing Pillow+ffmpeg architecture, scoped to `harder_to_ignore` only (income_vs_wealth / flash_real_estate left pixel/audio-identical).
- **What was built (all opt-in, wired only via `generate_hardertoignore.py:apply_to()`):**
  - `generate_video.py`: `post_process()` — filmic tone-curve LUT + precomputed vignette (numpy radial mask, `ImageChops.multiply`) + rotating film-grain tiles (`Image.effect_noise`, 8-tile cycle by frame index). Everything expensive is built once and cached at module scope.
  - `generate_video.py`: `camera_state()`/`apply_camera()` — beat-locked camera: slow per-beat drift (keyed off `local_beat`/`clip_beats`) plus a zoom "punch" on the same `stamp`/`slam` SFX events that already accent the audio (`camera_punch_events` reuses `sfx_events`), implemented as a crop-before-resize on the already-2x-supersampled frame so it's a net downsample, never upsampling blur.
  - Opt-in `shadow=` kwarg on `house`/`coin`/`gold_building` (flat offset-silhouette fill, no per-call GaussianBlur — cheap at ~3800 frames); `harder_to_ignore`'s local `card()` (28 call sites) made shadow-default-on.
  - `sfx_gen.py`: `pad_bed()` — quiet synthesized ambient pad (detuned sines + slow LFO + low-pass), normalized to its own quiet peak target (not `_norm()`'s 0.85, since a continuous bed's duration-weighted contribution to `mean_volume` dwarfs sparse SFX). `make_track()` takes `bed=`/`bed_gain=`; `generate_video.MUSIC_BED` flag gates it per-story.
  - `remix.py` gained a story-selector (`python remix.py harder_to_ignore`) mirroring `qa_check.py`'s `--video` pattern — SKILL.md's workflow assumed this worked for audio-only iteration but it silently always used the default `income_vs_wealth` `CLIPS`; needed it to tune `bed_gain` without a full ~30min re-render each time.
  - **Bug found and fixed (pre-existing, not introduced by this pass):** `pop_text()`'s scale-in formula (`generate_video.py`) never actually settled at `1.0x` — the smoothstep curve asymptoted to `(0.6+grow)x ≈ 1.7x` forever after the pop-in window. Invisible in isolation but caused adjacent same-beat labels (e.g. clip5's "BROKERS" / "YOUR MARKET" / "RELATIONSHIPS" under three separate cards, each correctly positioned 240px apart by layout_guard) to visually collide once fully rendered at 1.7x size — garbled overlapping text the collision audit couldn't catch because `text_box()` is sized at the *claimed* px, not the runtime-inflated one. Fixed by reusing the existing `elastic()` easeOutBack curve (already used elsewhere for exactly this "overshoot then settle at 1.0" shape) instead of the bespoke formula. ## Iteration 23 - Chatterbox voice cloning as a Studio voice option
- **Request:** add Chatterbox (free ElevenLabs alternative with voice cloning) as a voice option in the studio, test it, render the adi video with it.

- **Lesson:** adding a voice engine to a sync-driven pipeline is an alignment problem; forced alignment against the known script is more robust than transcribing (no word mismatches), and a content-addressed cache (tag = hash of reference clip + settings) makes switching back and forth free.
- **Iteration 23 follow-up (user cloned their own voice, "lee-001"):** the first full narration came out 88 s long (66 s expected) with 2-4 s holes. ## Iteration 29 - post-production editor: a CapCut-style timeline, SFX library, text and captions
- **Request:** an SFX library like the music library; cut / trim / split on the timeline, expand a selected clip from both sides by dragging; "lots and lots" of relevant post-production features, taking CapCut as the example.
- **Architecture: a non-destructive edit applied at export.** The render stays untouched. The edit is a small JSON per project and style; the page "compiles" it (video clips, audio pieces, text) into plain time ranges, and the same compiled list drives both the browser preview (WebAudio + the render's video element) and the export (`edit.py` builds one ffmpeg filter graph: every video clip is its own `-ss/-t` seek of the render so nothing is buffered; every audio clip is a `atrim/volume/afade/adelay` chain mixed per bus; the music bus is side-chain ducked by the voice bus; captions are an ASS file burned with libass).
- **Data model that makes restore work.** Video clips store base time (seconds of the original render), and the render's narration / effects are *derived* from the clip ranges, with per-sound overrides (`gone` ranges, `cuts`, gain, fades). So split / trim / reorder / delete move the sound with the picture, and dragging an edge outward brings back the cut picture AND voice, with no special case. Sounds you add are *free* items with their own place, with an optional Ripple. Detaching (dragging a render sound) hides its range and creates a free copy.
- **Features:** split / trim / expand from either edge (video, voice, effects, music, text), ripple delete, reorder scenes, duplicate, freeze frame, speed, video and audio fades, per-clip volume / mute, track levels and mutes, markers, snapping, zoom, undo / redo (150 steps), keyboard shortcuts, drag from the libraries, loop-to-fill music, music ducking, brightness / contrast / saturation, fade-out at the end, loudness normalisation, text clips, auto-captions with word highlight, an inspector, a resizable dock, an edit-changed safeguard when the render's timing changes.
- **Verification (all measured, not assumed):** an *unedited* export reproduces the render - 1919 identical frames (PSNR 56 dB) and audio within 0.5 dB; a heavy edit (tail trimmed, one clip at 1.5x, a freeze frame, loop music with fade, a built-in and a user effect, a deleted narration piece, 1 s end fade) exported to exactly the planned length (76.514 s, 1837 frames), the freeze frames are bit-identical, the effect tone is present at its position and absent right after, the music loops and fades, the last frame is dark (luma 227 -> 39); captions burned in with outline / box / highlight; playback across a cut lands on the right source time; split / delete / undo, trim and expand-back, move and detach were driven with real mouse and keyboard events.
- **Bugs found by testing:** (1) the freeze-frame chain produced a single frame (`tpad` cannot extend a one-frame stream) - the export was 0.85 s short; now `loop` + explicit timing; (2) ffmpeg's mono -> stereo up-mix lost 3 dB on the narration - mono is copied to both channels; (3) very short clips were almost all resize handle, so a move turned into a trim - handle width now scales with the clip; (4) while dragging, the grabbed piece was re-looked-up in the already-edited state where its key had changed, so only the first mouse-move took effect - it is resolved once when the drag starts; (5) `ED.sel.map(resolve)` leaked the array index into the new optional arguments; (6) a helper called `setStyle` clashed with the app's style switch.
- **Limits:** the edit applies to the project's latest render in the current format; a clip cannot be stretched beyond the end of its source (use Freeze, or Speed); no cross-fades between video clips (fade out / in instead). Image overlays (logo, stickers; `projects/<p>/assets`) were added at the end of the iteration: an Overlay lane, stage preview, and ffmpeg `overlay` with alpha fades - verified on a watermark (transparent at 0.05 s, solid at 10 s, fading out at the end of the export).
- **Lesson:** keep the *compiled* representation as the single contract between preview and export, and derive things (here the render's sound) instead of copying them - restore, ripple and undo all fall out of that for free.
