# Lee Gunasinghe - 7 reel test batch

Seven scripts for @lilanthagunasinghe, one a day. Each `.txt` file pastes straight into **New project > Script** in Flash Studio.
They follow the frameworks in `docs/FLASHACQ_SCRIPTS.md` and the house rule of no colons and no semicolons.

## Why this batch

His last eight reels repeated one idea (salary vs ownership), had no number, no proof and no reason to send or comment, and drew 0 to 2 likes each.
This batch fixes that with one rule per reel.

- One idea, named in the first line.
- One number you can follow out loud.
- One honest trade-off, which builds trust and keeps the page safe.
- One keyword, **DEAL**, in the last script lines, the first caption line and the bio.
- One line built to be sent to a friend.

The series is built around manufactured housing parks and small deals, because his September deal screenshots (lot rent, cap rate, seller financing) are the one thing nobody else in the niche can show.

## Assumptions to confirm

- Audience is US based investors and first time buyers. Change the loan and tax wording if not.
- All numbers are illustrative. If Lee can show real numbers from his own deals (anonymised if needed), swap them in. That will beat any example here.
- His voice or a voice he approves narrates. Do not clone a voice without his consent.

## How to test it

1. Post every reel as a **Trial Reel** first if the account has it, so non followers see it before the grid does. Promote the winner to the grid.
2. On reels 01 and 02, make a second cut with the alt hook and compare 3 second hold and watch through.
3. After 7 days, read these in Insights for each reel and keep the top two formats.

| Number | Why it matters |
|---|---|
| 3 second hold | Did the hook work |
| Average watch time vs length | Did the middle hold them |
| Sends per reach | The strongest signal for reaching new people |
| Non follower share of views | Is it leaving his circle |
| Comments with the keyword | Is the CTA working |

If the keyword gets comments but nothing is sent back, the auto reply is not set up. Fix that before post one.
