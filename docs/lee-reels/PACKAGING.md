## Every reel, the same routine

1. Post at the same time each day, one reel a day, in the order below.
2. Upload the clean file from `output/`. Choose the cover from `output/covers/`.
3. Paste the caption. The first line is the keyword offer.
4. Post the first comment yourself and pin it.
5. Share the reel to Stories with a question sticker.
6. Send it to 10 to 20 real people with one question, in the first hour.
7. Check the DEAL replies went out. Answer anything the automation cannot.

All numbers are examples. Keep the disclaimer line in every caption.
